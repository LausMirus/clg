1. Circular Queue

Queue where last position connects to first, forming a circle; reuses empty spaces.

2. Circular vs Simple Queue

· Simple: Cannot reuse empty spaces after deletion → memory waste
· Circular: Reuses empty spaces by wrapping around → memory efficient

3. Purpose of front and rear

· front: Points to first element (deletion end)
· rear: Points to last element (insertion end)
· Both move cyclically using % operator

4. Initial Values

· front = -1
· rear = -1

5. Operations on Circular Queue (size = 5)
